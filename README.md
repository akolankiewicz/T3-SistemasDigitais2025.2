# Sistema de Controle de Elevador em FPGA

## 📝 Implementação

Este projeto consiste na implementação de um **Sistema de Controle de Elevador de 5 Andares** utilizando a linguagem **Verilog** para síntese em **FPGA**.

A arquitetura é baseada em uma **Finite State Machine (FSM)** síncrona de alto nível, complementada por módulos de lógica combinacional e síncrona para gerenciar funcionalidades avançadas, como:

*   **Modo Standby** (Economia de Energia)
*   **Bloqueio de Andar** (Controle de Acesso)
*   Gerenciamento de chamadas e capacidade de passageiros.
